# Portfolio assets

**Pharmacy POS — by Shameer Azmi. MIT licensed.**

The 60-second MP4 is an **edited, captioned walkthrough of real application screens**, captured using fictional demo records. It is not a continuous live screen recording and has no audio. It covers role entry, catalogue, barcode/pack lookup, cart pricing, split payment recording, receipts, returns, expiry alerts, reports and operator stock receiving.

Download `pharmacy-pos-demo-60s.mp4` from the [portfolio demo release](https://github.com/azmishameer/pharmacy-pos/releases/tag/portfolio-demo-20260928). A poster and the original screenshots are in this folder. Embed the MP4 in your portfolio's video player; use the poster before playback and include captions/descriptive text for accessibility.

The interactive application is **locally runnable**, not hosted publicly. [Demo instructions](../docs/demo.md) provide Docker and Windows options. Docker/Windows integration and physical device testing are separate from the application/browser checks and have not been completed on this Mac.
